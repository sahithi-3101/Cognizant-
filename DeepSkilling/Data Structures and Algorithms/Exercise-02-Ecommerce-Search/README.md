# Exercise 02 - E-commerce Platform Search Function

## Objective

Implement Linear Search and Binary Search algorithms in C# and compare their performance using Big O notation.

## Scenario

An e-commerce platform needs a fast and efficient search mechanism to locate products based on their Product ID.

## Concepts Covered

* Big O Notation
* Best, Average, and Worst Case Analysis
* Linear Search
* Binary Search
* Time Complexity Analysis

## Files

* Product.cs
* SearchAlgorithms.cs
* Program.cs

## Complexity Analysis

### Linear Search

* Best Case: O(1)
* Average Case: O(n)
* Worst Case: O(n)

### Binary Search

* Best Case: O(1)
* Average Case: O(log n)
* Worst Case: O(log n)

## Conclusion

Binary Search is significantly faster than Linear Search for large datasets because it repeatedly divides the search space in half. It requires the data to be sorted before searching.

## Expected Output

* Product found using Linear Search
* Product found using Binary Search
* Time Complexity Comparison
