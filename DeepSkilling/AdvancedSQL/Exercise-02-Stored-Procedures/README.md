# Exercise 02 - Stored Procedures

## Objective

Implement SQL Stored Procedures to retrieve and insert employee records efficiently.

## Concepts Covered

* CREATE PROCEDURE
* Parameters
* EXEC
* INSERT
* SELECT
* Reusable SQL Logic

## Scenario

A company's HR system needs reusable database operations to retrieve employees by department and insert new employee records without repeating SQL statements.

## Stored Procedures Implemented

### 1. sp_GetEmployeesByDepartment

Retrieves employee details based on DepartmentID.

### 2. sp_InsertEmployee

Adds a new employee record into the Employees table.

## Benefits of Stored Procedures

* Improved performance
* Code reusability
* Enhanced security
* Easier maintenance
* Centralized business logic

## Learning Outcome

This exercise demonstrates how stored procedures encapsulate SQL statements into reusable database objects, making applications more secure and maintainable.
